# Fortune Cookie for the Liquidated Trader

> "You will find your stop-loss tomorrow, warm and comfortable, in the pocket you forgot to check."

One deterministic fortune-cookie line, written for the crypto trader who has just been liquidated. Entered in the make.fun competition [u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c?utm_source=github&utm_medium=readme&utm_campaign=u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c).

## Run

```bash
python3 main.py
```

Writes the fortune to `/output/entry.txt`, creating parent directories as needed.

Override the output path:

```bash
python3 main.py path/to/entry.txt
OUTPUT_PATH=path/to/entry.txt python3 main.py
```

Every run writes the exact same bytes. No dependencies, no network, no secrets.
